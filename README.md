# Capital Conecta+

Versão completa baseada no repositório GabOliveira19/CapitalConectaFinal, com a nova logo e identidade em preto, branco e laranja (#FF7900).

## Abrir

Abra index.html no navegador. Mantenha os arquivos HTML, brand-capital.css e a pasta assets juntos.

## Enviar pelo GitHub Desktop

1. Abra este repositório no GitHub Desktop.
2. Revise Changes e faça o commit com o título: Atualiza logo e identidade visual.
3. Use Publish repository caso este repositório ainda não tenha sido publicado, ou Push origin caso já tenha um destino.
4. Para publicar o site, habilite GitHub Pages na branch principal e pasta raiz.

A imagem original está em assets/images/capital-conecta-logo.png. O CSS enquadra a logo sem distorcer o arquivo e aumenta sua apresentação no cabeçalho.

Esta edição mantém as funcionalidades demonstrativas e os dados locais no navegador da versão de origem. A API SQL da versão separada não está incluída.
